# MLBB Помощник

Независимое Android-приложение на C# и .NET MAUI для быстрого поиска героев Mobile Legends: Bang Bang, их контрпиков и популярных сборок.

## Скачать APK

**Последняя версия:** [открыть релизы и скачать APK](https://github.com/XicxSs/MLBB-helper-2.0/releases/latest)

Если свежая сборка ещё не опубликована, APK можно получить из раздела **Artifacts** последнего успешного запуска [сборки Android](https://github.com/XicxSs/MLBB-helper-2.0/actions/workflows/android-apk.yml). Архив артефакта называется `MLBB-helper-Android-APK`.

На Android откройте скачанный APK и подтвердите установку. Если система попросит, разрешите установку приложений из выбранного источника. Приложению требуется Android 7.0 или новее.

## Возможности

- Каталог из 133 героев с портретами и синим свечением в интерфейсе.
- Поиск по русскому или английскому имени, роли и линии.
- Страница героя с контрпиками и популярными сборками.
- Варианты сборок показывают ключевые предметы, эмблему, таланты, заклинание и доступную статистику.
- Патч и список героев проверяются онлайн при запуске; контрпики и сборки обновляются при открытии профиля героя.
- Последние полученные данные сохраняются на устройстве. Каталог и базовые рекомендации остаются доступны без интернета.
- Сине-голубой интерфейс со стеклянными панелями и подсветкой портретов.
- Приложение не запрашивает данные игрового аккаунта и не вмешивается в игровой клиент.

## Сборка из исходного кода

Нужны .NET 10 SDK, workload Android для .NET MAUI и Java 17.

```bash
dotnet workload install maui-android
dotnet restore MlbbHelper.csproj
dotnet publish MlbbHelper.csproj \
  --configuration Release \
  --framework net10.0-android \
  --property:AndroidPackageFormat=apk
```

GitHub Actions автоматически собирает и публикует установочный APK при изменении текущей ветки. Проект включает проверку локального каталога, Android-портреты, иконку приложения и экран загрузки.

Чтобы проверить встроенный справочник локально:

```bash
python3 tools/validate_data.py
```

Скрипт `tools/build_seed_data.py` предназначен для обновления встроенного офлайн-снимка из checkout MLBBDex; он ожидает ImageMagick (`convert`). В обычной работе приложение получает новые данные через публичный API и переустанавливать APK для обновления патча не нужно.

## Источники и ограничения

Список героев, справочные материалы и портреты основаны на MLBBDex и Mobile Legends Wiki. Статистика контрпиков и сборок поступает из Rone Arena через MLBBDex. Встроенный снимок данных соответствует патчу **2.2.23** и обновлён **20 ноября 2026 года**; при подключении к интернету приложение проверяет более свежие сведения.

Контрпики и сборки — статистическая рекомендация, а не гарантия результата. Данные могут отличаться в зависимости от ранга, региона и времени измерения. Названия предметов в сборках оставлены на английском языке, как в источнике данных.

Подробная атрибуция, лицензии и уведомление о товарных знаках находятся в [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md). Это независимый фан-проект, не связанный с Moonton и не одобренный компанией.
